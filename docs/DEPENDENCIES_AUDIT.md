# Аудит зависимостей (фиксация рисков)

**Дата:** 2026-02. **Примечание:** Context7 недоступен; перед релизом повторить проверку через Context7 (CVE + Best Practices 2026).

## Backend (requirements.txt)

| Пакет | Версия | Риск / рекомендация |
|-------|--------|---------------------|
| fastapi | >=0.115.13 | Starlette CVE-2025-62727 (Range DoS), CVE-2025-54121 (multipart DoS). Рекомендация: обновить до 0.128.x (включает фиксы Starlette). |
| uvicorn | 0.30.6 | Оставить; при обновлении FastAPI проверить совместимость. |
| Pillow | 10.4.0 | CVE-2025-48379 не затрагивает 10.x (затрагивает 11.2.x DDS). Оставить с митигацией: не сохранять недоверенные DDS. |
| cryptography | >=42.0.0 | Актуальная ветка; периодически обновлять. |
| redis, celery | 5.1.1, 5.4.0 | Используются для фоновых задач; версии актуальные. |
| Остальные | см. requirements.txt | Зафиксированы; при обновлении — тесты и миграции. |

**Действия:** Обновить FastAPI (и starlette) до версии с фиксами CVE; остальное оставить с периодическим пересмотром.
