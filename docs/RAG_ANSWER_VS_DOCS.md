# Сверка ответов ИИ с документами RAG

В репозитории в `docs/rag/` лежат **три** файла (все прочитаны и сверены с ответами ИИ):
- **wb_packaging.txt** — общие требования WB (материалы, коробка, пузырчатая плёнка, габариты, паллеты)
- **ozon_packaging.txt** — короткий текст с общими принципами Ozon (без деталей по категориям)
- **Как_правильно_упаковать_разные_виды_товаров.docx** — инструкция WB (~26 тыс. знаков): разделы «Обувь», «Зеркала», «Посуда», «Упаковка хрупких товаров» и др.

---

## Справочник: что именно есть в документах (прочитано из файлов)

### wb_packaging.txt (полностью)

- Модель «Склад WB» (FBW). Материалы: пакет/рукав, заглушка, термоусадочная плёнка, пузырчатая плёнка, картонная коробка.
- **Стрейч и скотч:** запрещено использовать в качестве полноценной индивидуальной упаковки; скотч только для дополнительной фиксации допустимых видов упаковки.
- Пакет: от 25 мкм (текстиль), от 50 мкм (верхняя одежда, жидкое). Зип-застежка — герметично закрывать скотчем.
- Коробка: плотные закрывающие части, стикеры/скотч/резинка, товар не болтается, без посторонней маркировки.
- Пузырчатая: целые пузырьки, несколько слоёв, плотно натянута.
- **Габариты FBW:** Короб/Суперсейф — вес до 25 кг не включительно, одна сторона до 80 см, сумма сторон до 160 см. Монопаллета — до 25 кг, сторона до 120 см, сумма до 200 см; для Одежда/Обувь/Продукты/Косметика при монопаллете: 80 см, 160 см.
- Паллеты: деревянные евростандарт, 120×80×14,5 см.
- Общее: индивидуальная упаковка, штрихкод, защита от влаги и грязи; заводская упаковка не заменяет индивидуальную (кроме части Электроники).

**В файле нет:** правил упаковки обуви (бумага, силикагель, 50 мкм, исключения), зеркал, посуды, размеров этикеток Ozon, красного скотча.

### ozon_packaging.txt (полностью)

- Требования к упаковке Ozon (FBS). Источник: seller-edu.ozon.ru.
- Уточнять актуальные требования в ЛК продавца и в разделе «Требования к упаковке» по ссылке.
- Общие принципы: индивидуальная упаковка каждой единицы; сохранение товарного вида; маркировка по правилам Ozon для FBS.
- Для детальных требований по категориям и типам поставок — см. инструкции на seller-edu.ozon.ru.

**В файле нет:** размеров этикетки (58×40, 120×75 и т.д.), запрета красного скотча, правил по зеркалам, посуде, опасным грузам.

### Как_правильно_упаковать_разные_виды_товаров.docx (ключевые фрагменты)

- **Обувь:** обернуть бумагой или мешочки → коробка + поглотитель влаги (силикагель); крышку откидную/выкатную/съёмную фиксировать резинкой, скотчем или наклейками; можно термоусадочная плёнка. Коробка нужна для всех типов обуви, кроме: резиновых сапогов и шлёпанцев, резиновых балеток и кроссовок, резиновых сабо, тапочек и сандалий. Такую обувь можно поставлять в пакете плотностью не меньше 50 мкм с зип-застёжкой или клеевым клапаном.
- **Зеркала:** 1) картонная упаковка с пенопластом + укрепление углов + 2 слоя пузырчатой + стреп-лента; 2) бортики 7-слойного картона + пузырчатка/пенопласт + коробка из 5-слойного картона с вставками; 3) пузырчатка/пенопласт + деревянная обрешётка + пузырчатка поверх. Знак «Хрупкий груз».
- **Посуда** (стекло, фарфор, керамика, для приготовления): 2 слоя пузырчатой; коробка по размеру; пустоты — пузырчатка, вторичный картон или крафтовая бумага; при слабой заводской коробке — +1 слой пузырчатой. Жаропрочное стекло (крышки, формы): 2 слоя пузырчатой; без заводской коробки — плёнка + доп. коробка. Сковороды, кастрюли, ковши: внутри пузырчатая плёнка. Наборы: заводская упаковка допустима при фиксации. Знак «Хрупкий груз».
- **Упаковка хрупких товаров** (общий блок): двойной слой пузырчатой для мелких; 5-слойный или 3-слойный гофрокартон; наклейки или скотч «Осторожно, хрупкое!».

**Документ — инструкция Wildberries.** В нём нет требований Ozon (этикетки, скотч, FBS по категориям).

## 1. Упаковка обуви

**Что сказал ИИ:** бумага/мешочки, поглотитель влаги (силикагель), фиксация крышки резинкой/скотчем/наклейками, термоусадочная плёнка; исключения — резиновые сапоги/шлёпанцы/балетки/сабо/тапочки/сандалии в пакете ≥50 мкм с зип-застёжкой или клеевым клапаном; уточнить маркетплейс.

**Что есть в RAG:**
- **wb_packaging.txt**: «Обувь» только в габаритах (макс. сторона 80 см, сумма 160 см). Нет правил про бумагу, силикагель, 50 мкм, исключения.
- **ozon_packaging.txt**: общие принципы, без обуви.
- **Как_правильно_упаковать_разные_виды_товаров.docx** — раздел «Обувь» (цитата): *«Оберните обувь специальной бумагой или сложите в индивидуальные мешочки. Затем упакуйте пару в коробку и положите туда поглотитель влаги — например, пакетик с силикагелем; Если крышка коробки откидная, выкатная или полностью съёмная, обязательно зафиксируйте её резинкой, скотчем или наклейками… Также можно обернуть коробку термоусадочной плёнкой. Коробка нужна для упаковки всех типов обуви, кроме: резиновых сапогов и шлёпанцев, резиновых балеток и кроссовок, резиновых сабо, тапочек и сандалий. Такую обувь можно поставлять в пакете плотностью не меньше 50 мкм с зип-застёжкой или клеевым клапаном»*.

**Вывод:** Ответ ИИ **полностью совпадает** с текстом DOCX. Все пункты (бумага/мешочки, силикагель, фиксация крышки, термоусадочная плёнка, исключения и пакет 50 мкм) есть в документе.

## 2. Упаковка зеркала на ВБ

**Что сказал ИИ:** несколько слоёв пузырчатой плёнки, уголки картонные/пенопластовые, жёсткая коробка по размеру, фиксация наполнителем, скотч/стретч снаружи, для крупных зеркал — обрешётка или пятислойный гофрокартон, штрихкод, знаки «Хрупкое»/«Осторожно, стекло», фото при браке.

**Что есть в RAG:**
- **wb_packaging.txt**: пузырчатая плёнка (несколько слоёв, целые пузырьки), картонная коробка (плотное закрытие, скотч/резинка/стикеры). Нет «зеркало», «хрупкий груз», «уголки», «5-слойный».
- **Как_правильно_упаковать_разные_виды_товаров.docx** — раздел «Зеркала» (цитата): *«1-й вариант: плотно облегающая картонная упаковка с пенопластом внутри + дополнительное картонное укрепление всех углов + 2 слоя пузырчатой плёнки + стреп-лента. 2-й вариант: … транспортировочная коробка из 5-слойного картона с фиксацией картонными вставками внутри. 3-й вариант: пузырчатая плёнка или пенопласт + деревянная обрешётка без острых углов + пузырчатая плёнка поверх обрешётки. В любом случае нанесите на упаковку заметный знак «Хрупкий груз»»*. В блоке «Упаковка хрупких товаров»: *«Поверх упаковки обязательно нанесите наклейки или скотч «Осторожно, хрупкое!»»*.

**Вывод:** Ответ ИИ **совпадает** с DOCX: пузырчатка, уголки (картонное укрепление углов), коробка 5-слойного гофрокартона, обрешётка, знак «Хрупкий груз»/«Осторожно, хрупкое!». Штрихкод и «фото при браке» — из общих требований WB (wb_packaging.txt: «промаркирована штрихкодом»).
