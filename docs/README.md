## Обзор проекта

**Бирка** — Telegram Mini App для управления фулфилментом:

- **Клиенты** — компании, товары, заявки, отгрузки, прайс; просмотр статусов, остатков, фото брака; чат с AI-помощником.
- **Склад** — приёмка, упаковка, отгрузка заказов; печать этикеток; сканер штрихкодов; FBO-поставки WB/Ozon.
- **Админка** — пользователи и роли, адреса доставки, шаблоны договоров, прайс услуг, документы (RAG), настройки AI (OpenAI/OpenRouter).
- **Бот** — ответы пользователям с помощью AI по заявкам, товарам, остаткам, браку, отгрузкам, прайсу, реквизитам.

## Архитектура

- **Frontend** — SPA (React + Vite), статика через Nginx. Роли: клиент, склад (warehouse), админ.
- **Backend** — REST API (FastAPI), префикс `/api/v1`. Авторизация: `X-Session-Token` (после /auth/telegram) или `X-Telegram-Init-Data`.
- **PostgreSQL** — пользователи, компании, API-ключи WB/Ozon (шифровано), заказы, товары, услуги, отгрузки, FBO-поставки, шаблоны договоров, чат AI, настройки AI, RAG (pgvector).
- **S3** — в БД только ключ объекта; URL строится на бэкенде. После загрузки — HEAD-проверка. Фоновый планировщик — проверка просроченных отгрузок.
